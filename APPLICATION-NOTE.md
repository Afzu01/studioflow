# Project note for your application

**Project:** StudioFlow — appointment and client management dashboard

I built StudioFlow to demonstrate how I approach a practical business problem from interface to data layer. It is a responsive React dashboard backed by an Express REST API and SQLite. A studio owner can review the day’s bookings, search clients, create an appointment, track booking status, and export the schedule as CSV. The API validates booking data and keeps clients and appointments connected in a relational model.
